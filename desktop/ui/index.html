Menunggu Anda scan dari Telegram HP...
  1. 1. Buka aplikasi Telegram di HP Anda.
  2. 2. Masuk ke Settings ➔ Devices ➔ Link Desktop Device.
  3. 3. Arahkan kamera ke QR Code di atas.

Kode OTP dikirim ke chat resmi Telegram di HP Anda. Jika terkendala, pakai tab Scan QR.
